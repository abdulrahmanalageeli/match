# V12 recipe retraining with Events 27 and 28

Run date: 2026-09-17. Status: offline candidate trained and evaluated; production was not changed.

## Decision

**Better overall on the newer event data; worse for User 7.** The candidate improves all five aggregate metrics against frozen V12 on Events 27–28 when candidate predictions exclude each held-out person from training as both chooser and target. The same-fold comparison of old versus expanded training data also improves overall. User 7 regresses on both the operational final score and the subject-excluded diagnostic. Do not call this an across-the-board replacement for V12.

## Exact recipe and reproduction

- Frozen baseline: commit `35550c4`, model `2026-09-03-v12-event26-archetype-ai-chemistry-100`.
- Same questionnaire features; KMeans k=2, n_init=50, seed=2609; balanced logistic gate C=0.1; Ridge alpha=10, solver=lsqr.
- Same ranking-percentile target, original unweighted fit, empirical per-archetype calibration and geometric mean of both directions.
- Auto-saved directions are included in the primary fit, exactly as in the recovered V12 recipe. A separate manual-only sensitivity is reported below.
- No hyperparameter search or tuning against User 7 labels was introduced. The AI formula and its +12 / 0 / -8 correction remain unchanged.
- Event 26 replay reproduces all 1,348 scoring coefficients, the gate and calibration within 1e-8, and all five original cross-validation metrics within 1e-10. Its original NDCG@3 of 0.683023 is reproduced.
- The original numpy 2.1.1, scipy 1.16.0 and scikit-learn 1.7.0 versions were used.

## Verification and artifacts

- 240 Python-versus-JavaScript directional/mutual score comparisons match exactly. The diagnostic honors the existing runtime’s six-decimal gate-membership rounding; training/CV retain the original full-precision recipe.
- AI replay matches current content hashes and the supported semantic model tag; the same AI evidence is applied to each old/new model. No missing AI value is silently filled with a neutral score.
- Production code, model configuration, caches and database records were not changed.
- Candidate: `tmp/training-2026-09-17/candidate-config.json`.
- Detailed metrics: `tmp/training-2026-09-17/report.json`.
- User 7 runtime/AI replay: `tmp/training-2026-09-17/user7-runtime-ai-report.json`.
- Reproduction audit and OOF predictions are in the same directory.
- Training command: `python scripts/retrain-v12-events26-28.py`; runtime verification: `node scripts/verify-v12-retrain-user7.mjs`. Requires the ignored exports referenced in those scripts, the saved SQL exports and the pinned ML requirements. Raw temporary exports from this run are deleted after verification; hashes remain for provenance.

**Recommendation:** retain the candidate as an overall event-ranking improvement for prospective testing. Do not replace V12 on the claim that it improves User 7; it demonstrably does the opposite on the supplied benchmark. A future untouched event is needed to evaluate the final all-three-event artifact prospectively.
